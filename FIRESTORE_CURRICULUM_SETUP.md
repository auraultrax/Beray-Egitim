# Beray Müfredatını Firestore'a Yükleme

Admin hesabıyla öğretmen panelindeki **📚 Müfredatı Firestore'a Yükle** düğmesine bas. Fonksiyon; 5–12 sınıf için katalogdaki dersleri `courses`, ünite/konuları `lessons`, hazır testleri `tests` ve cevap anahtarlarını `testAnswers` koleksiyonlarına yazar.

Wordwall bağlantıları otomatik uydurulmaz. Wordwall etkinliğini siz oluşturduktan sonra konu/ders formundaki **🎮 Wordwall bağlantısı** alanına kendi HTTPS bağlantınızı girin. Wordwall resmi olarak etkinlik sayfası bağlantısı paylaşmayı ve web sitelerine embed kodu eklemeyi destekliyor.
